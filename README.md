# ESP32 呼吸监测 UI

该程序通过蓝牙低功耗（BLE）连接 ESP32，并订阅其输出的 CSV 数据：

```text
time_ms,raw,millivolts
```

界面提供实时呼吸曲线、混合呼吸频率估计和动态阈值。连接设备后会自动校准并开始监测，
无需选择设备、扫描设备或手动设置阈值；断开蓝牙时监测自动停止。

## 运行

在 PyCharm 中直接运行 `main.py`，或在终端执行：

```bash
/opt/anaconda3/bin/python main.py
```

## 使用步骤

1. 给 ESP32 接上已充电的 5V 移动电源并确认红灯亮起。
2. 在电脑上运行 `main.py`。
3. 点击“连接设备”。程序会在 10 秒内自动寻找 `BreathSensor-ESP32`。
4. 连接成功后自然呼吸约 8 秒，等待自动校准完成。
5. 测量中可直接按键盘 `1`–`9` 添加标记，标记会写入下一条采样数据。
6. 需要结束时点击“结束并保存”，程序会自动弹出 CSV 保存位置选择窗口。

导出的 CSV 包含 `time_ms,raw_pressure,mark` 三列。`time_ms` 从首条采样的 0 毫秒开始，
`raw_pressure` 是 ESP32 的原始压力值，`mark` 只能是 `1`–`9`；没有键盘标记的采样保存为 `NaN`。
如果取消保存，本次数据会保留，可再次点击“保存本次数据”。

首次运行时，macOS 可能询问是否允许 Python / PyCharm 使用蓝牙，请选择“允许”。
不需要在 macOS 系统蓝牙页面配对。

界面曲线滚动显示最近 30 秒的数据，但监测时长不受 30 秒限制。

## 动态阈值原理

- 前 8 秒学习当前佩戴状态下的压力基线和呼吸幅度。
- 使用最近 30 秒的 15%/85% 分位范围估计有效呼吸波动，降低异常动作的影响。
- 使用上下双阈值形成滞回，信号完整回落后再次越过上阈值才计为一次呼吸。
- 阈值每 0.5 秒平滑更新，可跟随佩戴松紧和姿势的缓慢变化。
- 呼吸频率取最近 6 个有效周期的中位数，降低单次误检的影响。

## 混合检测

- 动态阈值负责逐次呼吸标记和快速跟踪。
- 最近 24 秒信号每秒进行一次 ACF 自相关周期估计和 Welch 频谱估计。
- ACF 与频谱先形成共识，再与动态阈值结果复核；两者一致时加权输出。
- 两种结果明显冲突时暂停显示频率，不强行给出低可信数字。
- 周期复核因体动暂不可用时，仅在动态阈值信号质量足够时保留低置信输出。
- 逐次检测暂时漏掉低幅呼吸时，最近 6 秒仍具有足够周期信噪比才允许共识法接管。
- 超过 12 秒没有确认新呼吸时清空旧频率，避免屏息后继续显示历史值。

程序使用 `numpy` 和 `scipy` 完成周期与频谱分析；项目文档中的 Anaconda 环境已包含这些依赖。

该算法与界面用于原型监测，不用于医疗诊断。正式研究使用前仍需结合人工标注数据验证运动伪影、漏检和频率误差。
